# Data

Raw and processed data sources. Large files are excluded from git (see .gitignore).

## Sources
- NOAA Integrated Surface Database (ISD) - hourly station weather
- CAL FIRE FRAP - fire perimeter shapefiles
- ERA5 reanalysis - gridded climate variables

## Layout
- `cleaned/` - merged, feature-engineered tabular dataset
- `manifest.json` - file manifest / provenance
